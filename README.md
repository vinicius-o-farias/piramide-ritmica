# Pirâmide Rítmica

Treino de palhetada para guitarra: a pirâmide rítmica (1 a 8 notas por tempo, subindo e descendo em ciclos) numa pista estilo Guitar Hero. O app escuta sua interface de áudio, detecta cada palhetada e mostra o quanto você ficou cedo ou tarde.

Página: https://vinicius-o-farias.github.io/piramide-ritmica/

## Como usar

1. Abra a página no Chrome e clique em "Ativar entrada de áudio" para escolher sua interface.
2. Ajuste a sensibilidade até a barra passar da linha branca só quando você palhetar.
3. Rode "Calibrar ataque por densidade" (cerca de 30 segundos) no andamento em que você treina.
4. Clique em "Começar". Use fones, para o clique do metrônomo não entrar no microfone.

Sem entrada de áudio, Espaço ou toque na pista simulam a palhetada. Enter começa e para, Esc para.

O áudio é processado só no seu navegador; nada é enviado a servidor algum. As configurações ficam no armazenamento local do navegador.
